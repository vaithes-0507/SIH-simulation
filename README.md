## 🔍 Project Overview

AeroRakshak is an AI-powered autonomous disaster rescue drone concept designed to assist rescue teams in locating and verifying survivors in difficult and low-visibility environments.

### Core Features

- Adaptive multi-sensor search
- Thermal-first low-power scanning
- RGB + Edge AI survivor detection
- Acoustic + mmWave complementary sensing
- Sensor fusion and confidence-based verification
- GPS-degraded navigation support
- 5G / Wi-Fi 6 communication fallback
- Battery-aware mission safety
